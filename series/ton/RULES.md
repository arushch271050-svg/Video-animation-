# กฎทำทุก EP ของซีรีส์ "ต้น" (ผู้ใช้สั่ง 2026-10-27 — ใช้กับ EP2, EP3 และทุกตอนหลังจากนี้)

ผู้ใช้ส่งบทมา → ทำตามบทของผู้ใช้ (ไม่แก้เนื้อหาที่ไม่ได้สั่ง) แต่ "เล่า" ตามกฎด้านล่างทุกครั้ง โดยไม่ต้องรอสั่งซ้ำ
ถ้าบทไม่ชัด (ใครพูด, ฉากไหน) → ถามก่อน ห้ามเดา

## 1. เดินเรื่องแบบละครสั้นแนวตั้ง (micro-drama / "ละคร AI")
- **3 วินาทีแรกต้องมีฮุก**: เปิดกลางความขัดแย้ง หรือประโยคแรงที่สุดของตอน ไม่เปิดด้วยฉากตั้งฉากเงียบๆ
- **ต้นตอน EP2+**: เปิดด้วยปมค้างจากตอนก่อนใน 1 ช็อต/1 ประโยค แล้วไปต่อทันที (ไม่สรุปยาว)
- **ตัดถี่ 1.5–3 วิ/ช็อต**, กล้องไม่นิ่งตาย (push-in ช้าๆ ทุกช็อต, push-in เร็วตอนอารมณ์พีค)
- **ช็อตปฏิกิริยา (reaction)** หลังประโยคแรงทุกครั้ง: หน้าคนที่โดนพูดใส่ 0.6–1.2 วิ
- **เสียงประกอบตามจังหวะ**: riser ก่อนจุดพีค, impact ตอนตัดฉับ/เผยความจริง, heartbeat ตอนตึงเครียด
- **การ์ดตัวหนังสือ** ใช้น้อย และต้อง "กระแทก" (scale-in + สั่น + เส้นแดง) ไม่ค่อยๆ เฟด
- ความขัดแย้งชัด ตัวละครชัด (คนร้ายร้ายชัด แต่ไม่ใช่ทุกคนรวย = เลว ตามไบเบิล)

## 2. ฉากจบทุกตอน (cliffhanger) — โครงมาตรฐาน
1. ประโยค/การ์ดคำถามใหญ่ของตอน (กระแทก + riser)
2. **ภาพแวบอนาคต/ปริศนา** 2–3 วิ (letterbox, สโลว์, แฟลชขาว + impact) — ให้คนดู "เอ๊ะ อะไรต่อ"
3. **ภัยคุกคามบุกเข้ามา** (intrusion): เห็นหน้าศัตรู + เสียงเขา ไม่ใช่แค่ตัวหนังสือ
4. **หน้าต้นตอบสนอง** (เงยตามองกล้อง, push-in เร็ว)
5. **ตัดดำทันที** + เสียงตุบ → การ์ด EP ถัดไป (ไม่เฟดช้า)
- ประเภท cliffhanger ที่ใช้ได้: เปิดเผยความจริง / พลิกสถานการณ์ / เส้นตาย / มีคนบุกเข้ามา

## 3. เสียง
- **ต้น = เสียงโคลนของผู้ใช้** (F5-TTS-THAI v1, ref 0–7.45 วิ คลิป TikTok, speed 1.0, step 32 = "แบบ A" ที่ผู้ใช้เลือก)
- **ทุกบรรทัดต้องมีอารมณ์**: วิเคราะห์บริบทแล้วใส่ใน `vo/emotion.json` (shift/range/tempo/end/gain) → `tools/emote.py`
  - เยาะเย้ย/ดูถูก: สูงขึ้น ขึ้นลงกว้าง (range 1.6–1.8) · เศร้า/บรรยาย: ต่ำลง ช้าลง · ถาม: ท้ายเสียงขึ้น · ขู่/เด็ดเดี่ยว: ท้ายลงหนัก
- **ตัวละครต้องเสียงต่างกันชัด** (ห่าง ≥ 4 คีย์): ต้น ~112–120 Hz, ภาคิน ~145–170 Hz, แม่ ~200+ Hz; ตัวใหม่เลือก ref ใหม่ (Common Voice)
- **เสียงหัวเราะทั้งแก๊ง ต้องรัว** "ฮ่าฮ่าฮ่า" หลายเสียงซ้อน: `tools/laugh.py` (F5 หัวเราะเองไม่ได้)
- ตรวจทุกบรรทัดด้วยการถอดเสียงกลับ (whisper large-v3) ให้ตรงบทก่อนใช้; คำสั้นมาก (เช่น "ความรู้") ใช้ `fix_duration`
- เสียงบรรยากาศแยกฉาก + ลดลงอัตโนมัติตอนมีคนพูด (mix.py sidechain); ความดังรวม −14 LUFS ±1

## 4. หนังสือ CK
- **EP1: ห้ามเฉลย** — หนังสือในจอชื่อ "เปลี่ยนอนาคต" (ปกดำ ตัวแดง, ราคา ฿349, รีวิว) ไม่มีชื่อผู้แต่ง/หน้าคน
